# Lab 1.2 — Data examples

This directory contains examples of input-output pairs used in the thesis project.

In this project, X represents the input source code or software component that needs to be tested. It can be a C# method, service class, validator, or API endpoint.

The output y represents the generated unit test result. In most cases, y is an xUnit test class that checks expected behavior, edge cases, dependencies, and error-handling branches.

These examples are used to demonstrate how the proposed GenAI-based unit test generation system works as an end-to-end AI solution.

See [the example pairs](examples.csv) and the [Lab 1.2 process description](../labs/1.2-end-to-end/README.md).
